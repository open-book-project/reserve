    Reference¶

    This part collects what you need to look up while you work: the error messages PHP and MySQL give and what causes them, one-screen summaries of PHP, SQL and jQuery, the built-in functions grouped by the job they do, a security checklist, and a quick reference for XAMPP. Near the end are two lists for revision: the pairs of things that examinations ask you to distinguish, and the programs that a student should be able to write from memory.

    Error messages, decoded¶

    Start here. Nearly every hour lost on this course is lost to one of these eight, and each has one usual cause.

    Message Means Usually
    Parse error: syntax error, unexpected … PHP could not read the file at all; nothing ran A missing ; or } — and it is usually on the line before the one named, because that is where PHP first noticed
    Warning: Undefined variable $x Read before it was written A typo in the name, or a form field that was not submitted. Use ?? ""
    Warning: Undefined array key "x" That key is not in the array An unticked checkbox, a misspelt name attribute, or the page opened directly with no form behind it
    Warning: Cannot modify header information — headers already sent by (output started at file:line) Something was output before header(), session_start() or setcookie() A blank line before <?php, or a newline after ?> in an included file. The message names the real culprit — read the file and line in the brackets
    Fatal error: Uncaught Error: Call to undefined function foo() No such function A misspelling, or an extension that is not enabled
    Fatal error: Uncaught Error: Call to a member function query() on bool You called a method on false The connection or the query failed and its return value was never checked
    mysqli_fetch_assoc(): Argument #1 must be of type mysqli_result, bool given The same thing, procedurally mysqli_query() returned false. Print mysqli_error($conn)
    Uncaught ReferenceError: $ is not defined jQuery is not there yet Your script tag comes before jQuery's, or jQuery failed to load — check the Network tab

    The four-step debugging routine

    1. Read the message, all of it, including the file and line in brackets. 2. echo or var_dump() the value just above the failing line — never guess what a variable holds. 3. For a query, print the SQL and paste it into phpMyAdmin. 4. For anything in the browser, open the console (F12) before saying "nothing happens".

    put this at the top while developing

    <?php
// Show every error while you are building. Never on a live site.
error_reporting(E_ALL);
ini_set('display_errors', 1);

    XAMPP shows errors by default. A blank white page usually means they have been turned off — turn them back on before doing anything else.

    PHP syntax, on one screen¶

    everything.php

    <?php                                   // open. Close with ?> only if HTML follows

// ---- variables and constants ----
$name   = "Zoya";                       // no type declared
$marks  = 82;                           // case-sensitive names
define("PASS", 40);                     // constant: no $, global
const  COLLEGE = "Example";           // top-level only

// ---- strings ----
echo 'single: $name';                   // literal
echo "double: $name and {$arr['k']}";   // interpolated
echo 'joined ' . "with a dot";          // . not +
$s .= "appended";

// ---- arrays ----
$list  = [1, 2, 3];                     // keys 0,1,2
$assoc = ["name" => "Zoya", "marks" => 82];
$table = [["a" => 1], ["a" => 2]];      // rows
$list[] = 4;                            // append

// ---- conditions ----
if ($m >= 90)      { }
elseif ($m >= 40)  { }
else               { }

switch ($g) { case "A": break; default: }
$r = $m >= 40 ? "Pass" : "Fail";        // ternary
$v = $input ?? "default";               // null coalescing

// ---- loops ----
while ($i < 5)          { $i++; }
do { $i++; } while ($i < 5);
for ($i = 0; $i < 5; $i++) { }
foreach ($assoc as $k => $v) { }
foreach ($list as &$v) { $v *= 2; } unset($v);   // by reference

// ---- functions ----
function grade($m, $pass = 40) { return $m >= $pass ? "P" : "F"; }
function addOne(&$x) { $x++; }          // by reference
function total(...$n) { return array_sum($n); }
$double = function ($x) { return $x * 2; };
$triple = fn($x) => $x * 3;

// ---- the alternative syntax, for templates ----
?>
<?php if ($m >= 40): ?>
  <p>Passed with <?= $m ?></p>
<?php else: ?>
  <p>Failed</p>
<?php endif; ?>

<?php foreach ($rows as $row): ?>
  <tr><td><?= htmlspecialchars($row["name"]) ?></td></tr>
<?php endforeach; ?>

    PHP functions, by the job they do¶

    Finding out what you have¶

    Function Does
    var_dump($x) type, value and length — the debugging tool
    print_r($x) a readable array; print_r($x, true) returns it instead
    gettype($x) the type as a word
    isset($x) exists and is not null
    empty($x) falsy or missing — beware, "0" is empty
    is_numeric, is_string, is_array, is_int type tests

    Strings — Unit 2¶

    Job Function Example
    Length strlen / mb_strlen bytes / characters
    Case strtoupper, strtolower, ucfirst, ucwords
    Trim trim, ltrim, rtrim second argument sets the characters
    Slice substr($s, 2, 5) negative start counts from the end
    Find strpos test with === false
    Contains str_contains, str_starts_with, str_ends_with PHP 8, boolean, no trap
    Replace str_replace, substr_replace, strtr strtr avoids double replacement
    Split / join explode, implode, str_split separator first, both times
    Repeat / pad str_repeat, str_pad
    Reverse strrev
    Compare strcmp, strcasecmp returns −1, 0 or 1
    Format printf, sprintf, number_format %s %d %.2f %05d %-10s
    Make safe for HTML htmlspecialchars on every echoed user value
    Newlines to breaks nl2br after htmlspecialchars, not before
    Patterns preg_match, preg_replace, preg_split anchor with ^ and $

    Arrays — Unit 1¶

    Job Function
    Size count
    Add / remove at the end $a[] = $v, array_pop
    Add / remove at the front array_unshift, array_shift
    Is it there in_array (value), array_key_exists (key)
    Where is it array_search — returns the key or false
    Keys / values array_keys, array_values
    Join two array_merge, or $a + $b (first wins)
    A piece array_slice
    Totals array_sum, array_product, max, min
    One column of a table array_column($rows, "name")
    Transform / filter / fold array_map, array_filter, array_reduce
    Duplicates, reverse, flip array_unique, array_reverse, array_flip
    Make a range range(1, 10), range('a','z')
    Sort by Keys thrown away Keys kept
    value, ascending sort asort
    value, descending rsort arsort
    key — ksort / krsort
    your own rule usort uasort / uksort

    Forms and the request — Unit 3¶

    Thing Use
    Query-string values $_GET["q"] ?? ""
    Posted fields $_POST["name"] ?? ""
    Was this a submission $_SERVER["REQUEST_METHOD"] === "POST"
    A checkbox isset($_POST["agree"])
    A checkbox group x[] $_POST["x"] ?? []
    Validate an email filter_var($e, FILTER_VALIDATE_EMAIL)
    Validate an integer filter_var($n, FILTER_VALIDATE_INT) !== false
    Redirect header("Location: x.php"); exit;
    Remember a user session_start(); then $_SESSION["user"]
    Sign out $_SESSION = []; session_destroy();
    Set a cookie setcookie("theme", "dark", time() + 86400);

    MySQL — Unit 4¶

    Procedural Object Does
    mysqli_connect($h,$u,$p,$db) new mysqli($h,$u,$p,$db) connect
    mysqli_connect_error() $conn->connect_error why it failed
    mysqli_query($conn,$sql) $conn->query($sql) run; false on failure
    mysqli_error($conn) $conn->error the message
    mysqli_fetch_assoc($r) $r->fetch_assoc() next row as an array
    mysqli_num_rows($r) $r->num_rows rows in a SELECT
    mysqli_affected_rows($conn) $conn->affected_rows rows changed — takes the connection
    mysqli_insert_id($conn) $conn->insert_id the AUTO_INCREMENT just used
    mysqli_prepare($conn,$sql) $conn->prepare($sql) a prepared statement
    mysqli_stmt_bind_param($s,"is",…) $stmt->bind_param("is",…) i s d b, one per ?
    mysqli_stmt_execute($s) $stmt->execute() run it
    mysqli_stmt_get_result($s) $stmt->get_result() the rows

    the five patterns worth memorising

    // 1. connect
$conn = mysqli_connect("localhost", "root", "", "college");
if (!$conn) die("Connection failed: " . mysqli_connect_error());

// 2. select and loop
$result = mysqli_query($conn, "SELECT name, marks FROM students ORDER BY marks DESC");
if (!$result) die("Query failed: " . mysqli_error($conn));
while ($row = mysqli_fetch_assoc($result)) {
    echo htmlspecialchars($row["name"]), " — ", (int) $row["marks"], "<br>";
}

// 3. insert, safely
$stmt = mysqli_prepare($conn, "INSERT INTO students (roll, name, marks) VALUES (?, ?, ?)");
mysqli_stmt_bind_param($stmt, "isi", $roll, $name, $marks);
mysqli_stmt_execute($stmt);
echo mysqli_affected_rows($conn) . " row added";

// 4. one row only
$stmt = mysqli_prepare($conn, "SELECT * FROM students WHERE roll = ?");
mysqli_stmt_bind_param($stmt, "i", $roll);
mysqli_stmt_execute($stmt);
$row = mysqli_fetch_assoc(mysqli_stmt_get_result($stmt));
if (!$row) { echo "No such student"; }

// 5. search with LIKE — the wildcards go in the value
$pattern = "%" . $q . "%";
$stmt = mysqli_prepare($conn, "SELECT * FROM students WHERE name LIKE ?");
mysqli_stmt_bind_param($stmt, "s", $pattern);

    JSON — Unit 5¶

    Function Does
    json_encode($v) PHP value → JSON string. Gapless integer keys give an array; anything else an object
    json_encode($v, JSON_PRETTY_PRINT) readable, for debugging
    json_decode($s) JSON → objects, read with ->
    json_decode($s, true) JSON → associative arrays, read with []
    json_last_error_msg() why a decode returned null
    header("Content-Type: application/json"); first line of every endpoint
    file_get_contents("php://input") a JSON request body — it does not arrive in $_POST

    SQL, on one screen¶

    everything.sql

    -- ---------- databases and tables ----------
CREATE DATABASE IF NOT EXISTS college;
USE college;
SHOW TABLES;
DESCRIBE students;
DROP TABLE IF EXISTS students;

CREATE TABLE students (
    roll   INT          PRIMARY KEY,        -- or: INT AUTO_INCREMENT PRIMARY KEY
    name   VARCHAR(50)  NOT NULL,
    course VARCHAR(10),
    marks  INT          DEFAULT 0,
    email  VARCHAR(60)  UNIQUE,
    joined DATE,
    fee    DECIMAL(8,2),                    -- money: never FLOAT
    FOREIGN KEY (course) REFERENCES courses(code)
);

ALTER TABLE students ADD COLUMN city VARCHAR(30);
ALTER TABLE students DROP COLUMN city;

-- ---------- create ----------
INSERT INTO students (roll, name, marks) VALUES (2231045, 'Zoya', 82);
INSERT INTO students (roll, name, marks) VALUES (1,'A',50), (2,'B',60);   -- many rows

-- ---------- retrieve ----------
SELECT * FROM students;
SELECT name, marks FROM students WHERE marks >= 40;
SELECT DISTINCT city FROM students;

--   the clause order is fixed:
SELECT   c.title, COUNT(s.roll) AS n, ROUND(AVG(s.marks)) AS avg_marks
FROM     courses c
LEFT JOIN students s ON s.course = c.code
WHERE    c.fee < 25000
GROUP BY c.title
HAVING   COUNT(s.roll) > 0
ORDER BY avg_marks DESC
LIMIT    5 OFFSET 0;

--   WHERE operators
WHERE marks BETWEEN 40 AND 59
WHERE course IN ('BSCCS', 'BCOM')
WHERE name LIKE 'A%'          -- % any run, _ exactly one
WHERE email IS NULL           -- never  = NULL

-- ---------- update and delete ----------
UPDATE students SET marks = marks + 5 WHERE course = 'BAECO';
DELETE FROM students WHERE marks < 40;
TRUNCATE TABLE students;      -- empties it, keeps the structure

    Aggregates: COUNT, SUM, AVG, MIN, MAX. WHERE filters rows before grouping; HAVING filters groups after.

    jQuery, on one screen¶

    everything.js

    $(function () {                       // = $(document).ready(...)

  // ---- selectors ----
  $("p")                              // every <p>
  $("#total")                         // by id
  $(".error")                         // by class
  $("input[type='text']")             // by attribute
  $("ul li")  $("ul > li")            // descendant / direct child
  $("tr:even")  $("li:first")  $("input:checked")
  $(this)                             // inside a handler

  // ---- reading and writing ----
  $("#p").text()                      // get
  $("#p").text("new")                 // set — escapes, use for user data
  $("#p").html("<b>x</b>")            // set as markup — never with user data
  $("#name").val()                    // form fields
  $("#a").attr("href", "x.php")       // attributes
  $("#c").prop("checked", true)       // live properties
  $("#p").css("color", "red")
  $("#p").addClass("on").removeClass("off").toggleClass("hi")

  // ---- structure ----
  $("#list").append("<li>new</li>")
  $("<div>").text(name).appendTo("#out")     // the safe way to build
  $("#p").remove()  $("#list").empty()
  $("#p").show()  .hide()  .toggle(200)  .fadeIn()  .slideUp()

  // ---- events ----
  $("#b").on("click", function (e) { … })
  $("#f").on("submit", function (e) { e.preventDefault(); … })
  $("#q").on("input keyup change blur focus", fn)
  $("#list").on("click", ".del", fn)         // DELEGATED — for elements added later

  // ---- loops ----
  $("li").each(function (i) { $(this).text(i); })
  $.each(array, function (i, item) { … })

  // ---- AJAX ----
  $.get("x.php", { id: 5 }, function (text) { … })
  $.post("save.php", $("#f").serialize(), function (r) { … }, "json")
  $.getJSON("data.php", { q: term }, function (data) { … })

  $.ajax({
      url: "x.php", type: "POST", data: { id: 5 }, dataType: "json",
      success: function (d) { … },
      error:   function (xhr, status, err) { … }        // never omit this
  });
});
    JavaScript jQuery
    document.getElementById("x") $("#x")
    document.querySelectorAll(".c") $(".c")
    el.textContent = "x" $(el).text("x")
    el.addEventListener("click", fn) $(el).on("click", fn)
    fetch(url).then(r => r.json()) $.getJSON(url, fn)

    The security checklist¶

    Six lines. Every one of them is a question an examiner may ask, and every one is a real hole in a real student project.

    Where the value goes What protects it What happens without it
    Into an HTML page htmlspecialchars($v) Cross-site scripting: the visitor's browser runs someone else's markup
    Into an HTML attribute htmlspecialchars($v, ENT_QUOTES) and quote the attribute The same, escaping out of value="…"
    Into an SQL query a prepared statement SQL injection: the data becomes part of the program
    Into a table or column name a whitelist — placeholders cannot bind names The same, by another route
    Into a URL urlencode($v) A broken link, or a parameter smuggled into the next one
    Into JavaScript json_encode($v), and .text() not .html() at the other end XSS again, delivered through your own API

    And two rules that are not about escaping

    Never trust anything the browser sends — required, maxlength, a dropdown's options and a hidden field are all editable. And never store a password you can read: password_hash() on the way in, password_verify() on the way out.

    XAMPP quick reference¶

    Thing Where
    Your files go in C:\xampp\htdocs\
    Reach them at http://localhost/yourfolder/file.php
    phpMyAdmin http://localhost/phpmyadmin/
    Default MySQL login user root, no password
    PHP settings C:\xampp\php\php.ini — restart Apache after editing
    Apache error log C:\xampp\apache\logs\error.log
    Port 80 already in use Usually Skype or IIS. Change Apache to 8080 in httpd.conf, then use http://localhost:8080/
    Back up a database phpMyAdmin → the database → Export → Go. Keep the .sql file with your practical file

    Where to look things up¶

    • php.net/manual — the authority. Every function page ends with user-contributed examples, which are often the clearest part. Searching for php strpos lands you there directly.
    • dev.mysql.com — the MySQL reference manual.
    • api.jquery.com — every jQuery method, with a runnable demonstration on each page.
    • developer.mozilla.org — for HTML, CSS and JavaScript. Better than any other source for the DOM.
    • w3schools.com/php and tutorialspoint.com/php — named in the course outline; good for a first look, less good for detail.
    • The four prescribed books, listed under Further Reading at the end of this book.

    Differences at a glance¶

    The most reliably examined question type on this course. Answer each in a table with three or four rows.

    Compare The one-line distinction Unit
    echo / print echo takes many arguments and returns nothing; print takes one and returns 1 1
    == / === value after conversion / value and type 1
    include / require warning and continue / fatal error and stop 1
    variable / constant $, changeable, scoped / no $, fixed, global 1
    while / do…while tests first / tests after, so it always runs once 1
    sort() / asort() discards the keys / keeps them 1
    indexed / associative array integer keys from 0 / keys you choose 1
    single / double quotes literal / interpolates variables and escapes 2
    strlen / mb_strlen bytes / characters 2
    str_replace / preg_replace exact text / a pattern 2
    GET / POST in the URL, visible, small / in the body, hidden, large 3
    $_GET / $_REQUEST query string only / GET, POST and cookies merged 3
    session / cookie stored on the server / stored in the browser 3
    client-side / server-side validation convenience, bypassable / security, authoritative 3
    validation / sanitisation is it acceptable, reject it / is it safe here, transform it 3
    isset() / empty() does it exist and is not null / is it falsy or missing (beware "0") 3
    DBMS / RDBMS stores data / stores it in related tables with keys 4
    primary / foreign key identifies this row / points at another table's row 4
    WHERE / HAVING rows before grouping / groups after 4
    INNER / LEFT JOIN only matches / every left row, nulls where unmatched 4
    num_rows / affected_rows rows a SELECT returned / rows a write changed 4
    DELETE / TRUNCATE / DROP rows with a WHERE / all rows, keeping the table / the table itself 4
    mysqli / PDO MySQL only / many databases, nicer prepared statements 4
    JavaScript / jQuery the language / a library written in it 5
    .text() / .html() escapes markup / renders it 5
    .val() / .text() form fields / the text inside an element 5
    direct / delegated handler elements that exist now / elements added later too 5
    json_encode / json_decode PHP to JSON text / JSON text to PHP 5
    synchronous / asynchronous the script waits / it carries on and a callback runs later 5

    Programs to write from memory¶

    Each of these has appeared as a "write a program" question. Try each on paper, then check it by running it on your own server.

    Program The technique it tests
    Reverse the digits of a number % 10 and intdiv() in a loop
    Check a palindrome normalise, then strrev or two pointers
    Factorial, Fibonacci, prime, Armstrong, GCD loops and functions
    Sum of digits arithmetic or str_split + array_sum
    Multiplication table / star and number patterns nested loops, printf
    Count vowels, consonants, digits and spaces one pass, ordered tests
    Two text boxes and an Evaluate button self-processing form
    Six string operations with buttons one name, many values
    Login form with validation and redirect sessions, header()
    Registration form with $_POST and $_GET every input type, sticky redisplay
    Connect, insert, delete, display with JOIN / ORDER BY / GROUP BY the whole of Unit 4
    Change colour and contents on a click .css(), .text(), .click()
    Select by id, class, element and attribute jQuery selectors
    Form data to a JSON object, passed to another page JSON.stringify / parse

    The ten most-asked questions¶

    If time is short, these ten are the ones to be certain of. Every one has appeared in some form in almost every paper on this course.

    1. Difference between GET and POST, with when to use each. (Unit 3)
    2. What is SQL injection, and how does a prepared statement prevent it? (Unit 4)
    3. Difference between == and ===. (Unit 1)
    4. What are the superglobals? Name five and say what each holds. (Unit 3)
    5. Explain session versus cookie. (Unit 3)
    6. Write the code to connect to MySQL and display a table of rows. (Unit 4)
    7. Difference between include and require. (Unit 1)
    8. What is AJAX? Write a jQuery call that fetches JSON. (Unit 5)
    9. Explain JSON, and json_encode versus json_decode. (Unit 5)
    10. Write a PHP program to validate a registration form on the server. (Unit 3)
