    Preface¶

    This tutorial was written to accompany the FPGA and ASIC Agents and Skills project — a complete, open-source design pipeline that takes a hardware idea from a text specification all the way to a fabrication-ready GDSII file.

    The project exists because chip design has historically been locked behind expensive proprietary tools and non-disclosure agreements. Thanks to efforts from Google, SkyWater Technology, Efabless, and the open-source EDA community, it is now possible for any engineer with a laptop to design and even fabricate a real silicon chip at no cost.

    This tutorial assumes you can write code in some programming language and understand binary numbers. No prior hardware or electronics knowledge is assumed. Every concept is introduced with an analogy before any mathematics, and every code listing is taken directly from a real file in the project so you can run it yourself.

    Good luck, and happy taping out!
