    Appendix B: Glossary¶

    ASIC
    Application-Specific Integrated Circuit — a chip manufactured for one fixed purpose.
    AXI4
    Advanced eXtensible Interface version 4 — ARM’s bus protocol standard.
    BMC
    Bounded Model Checking — formal verification technique that checks properties up to \(k\) clock cycles.
    CDC
    Clock Domain Crossing — transferring signals between different clock domains.
    CLB
    Configurable Logic Block — the basic cell of an FPGA containing LUTs and flip-flops.
    CTS
    Clock Tree Synthesis — inserting buffers to balance clock arrival time across the chip.
    DRC
    Design Rule Check — verifying that a layout obeys the foundry’s manufacturing rules.
    DSP
    Digital Signal Processing — or the dedicated DSP slice hardware block in FPGAs.
    FPGA
    Field-Programmable Gate Array — a chip that can be reconfigured to implement any circuit.
    FSM
    Finite State Machine — a circuit that moves between a fixed set of named states.
    GDS/GDSII
    Graphic Design System II — the standard file format for chip layouts.
    HDL
    Hardware Description Language — a language for describing circuits (e.g. SystemVerilog).
    IP
    Intellectual Property — a reusable hardware block (core) with a standard interface.
    ISA
    Instruction Set Architecture — the set of instructions a processor can execute.
    LEF
    Library Exchange Format — abstract physical description of cells for place-and-route.
    LUT
    Look-Up Table — the basic logic element in an FPGA; implements any truth table.
    LVS
    Layout vs. Schematic — check that the physical layout matches the logical netlist.
    MPW
    Multi-Project Wafer — a wafer run shared by multiple designers to reduce cost.
    PDK
    Process Design Kit — everything the tools need to target a specific manufacturing process.
    PnR
    Place and Route — placing cells on the chip and routing the connecting wires.
    RISC-V
    An open-source instruction set architecture (ISA) with a modular extension system.
    RTL
    Register Transfer Level — a hardware abstraction describing data flow between registers.
    STA
    Static Timing Analysis — verifying that all signals meet timing requirements.
    SVA
    SystemVerilog Assertions — formal properties written in SystemVerilog syntax.
    WNS
    Worst Negative Slack — the most critical timing violation; must be \(\geq 0\) to pass.
    XDC
    Xilinx Design Constraints — Vivado’s constraint file format (TCL-based).
