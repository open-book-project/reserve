    Chapter 5: Standard DDR SDRAM: From SDR to DDR6¶

    DDR SDRAM is the main memory of personal computers and servers. It is optimised for the lowest cost per bit and for large capacities, with modules that plug into slots. This chapter follows the family generation by generation, from the first synchronous DRAM of 1993 to DDR5 and the DDR6 that is in development, and shows what changed each time: the prefetch, the voltage, the topology, the error handling. It then looks closely at what made DDR5 the largest architectural change in the series.

    5.1 What "double data rate" means¶

    SDRAM (synchronous DRAM) is DRAM whose interface follows a clock. The first SDRAM moved data once per clock cycle. Double data rate SDRAM moves data on both the rising and the falling edge, doubling throughput without doubling the clock. A DDR4-3200 module therefore runs a 1600 MHz clock.

    Inside the chip, the DRAM array has stayed at only a few hundred MHz across all generations. The interface speeds up by fetching more bits per data pin from the array at once, and the prefetch has doubled from 2n (DDR) to 4n (DDR2), 8n (DDR3) and 16n (DDR5). DDR4 kept 8n and added bank groups.

    Example 5.1: How fast does the array really run?

    Divide the data rate by the prefetch to get the rate at which the array is accessed.

    Generation Data rate (MT/s) Prefetch Array access rate
    DDR-400 400 2n 200 MHz
    DDR2-800 800 4n 200 MHz
    DDR3-1600 1600 8n 200 MHz
    DDR4-3200 3200 8n 400 MHz
    DDR5-6400 6400 16n 400 MHz

    Across a factor of 16 in data rate, the array access rate has only doubled. DDR4 kept the 8n prefetch and so had to speed up the array itself, but it eased the burden with bank groups, which let commands to different groups overlap.

    DDR5 made the biggest architectural changes of the family:

    • Two independent 32-bit sub-channels per DIMM instead of one 64-bit channel, so more requests can run in parallel.
    • An on-DIMM PMIC (power-management IC): voltage regulation moved from the motherboard onto the module, giving cleaner power at 1.1 V.
    • On-die ECC inside every chip, to keep dense chips reliable.
    • Same-bank refresh, which refreshes one bank in each bank group while the others keep working, instead of stalling the whole chip.
    • Burst length 16, up to 32 banks in 8 bank groups, and receiver equalisation to handle the higher speeds.

    DDR6 is in development at JEDEC, the industry body that writes memory standards (Section 5.8).

    5.2 SDR SDRAM (1993)¶

    Single data rate SDRAM replaced the asynchronous FPM and EDO DRAM of the early 1990s (Chapter 7). Synchronising to the system bus clock let the controller pipeline commands, and multiple internal banks let one bank open a row while another transferred data. PC66, PC100 and PC133 modules ran at 66 to 133 MHz on a 3.3 V supply, giving about 1 GB/s on a 64-bit bus. SDR SDRAM powered the Pentium II and Pentium III era and is now obsolete outside some very old industrial equipment.

    5.3 DDR (2000)¶

    The first DDR generation transferred data on both clock edges using a 2n prefetch, giving 200 to 400 MT/s at 2.5 V and up to 3.2 GB/s per 64-bit channel. It introduced a data strobe signal (DQS) that travels with the data, so that the receiver knows exactly when to sample it. DDR used 184-pin DIMMs and was the mainstream memory for Athlon XP and Pentium 4 PCs. It is obsolete.

    5.4 DDR2 (2003)¶

    DDR2 doubled the prefetch to 4n, so the interface could run twice as fast as the array: 400 to 1066 MT/s at 1.8 V, up to about 8.5 GB/s per channel. It added on-die termination (ODT), resistors inside the chip that absorb signal reflections and so improve signal quality on busy buses (Chapter 12). Latency in cycles went up, but latency in nanoseconds stayed similar. DDR2 used 240-pin DIMMs and is obsolete.

    5.5 DDR3 and DDR3L (2007)¶

    DDR3 moved to an 8n prefetch and 800 to 2133 MT/s at 1.5 V; the low-voltage DDR3L version runs at 1.35 V. Peak bandwidth reached about 17 GB/s per channel. DDR3 introduced the fly-by topology, where command and address signals pass each chip on the module in turn, with write levelling to compensate for the different arrival times (Section 12.4). DDR3 had a long life, and DDR3L is still found in some embedded boards and industrial systems.

    5.6 DDR4 (2014)¶

    DDR4 kept the 8n prefetch but organised banks into bank groups (typically 4 groups of 4 banks), allowing faster back-to-back access to different groups. It ran at 1600 to 3200 MT/s in the JEDEC standard (enthusiast modules went higher) at 1.2 V, giving 25.6 GB/s per channel at 3200 MT/s. Other additions were pseudo-open-drain I/O to save power, data bus inversion and CRC error detection on writes. DDR4 served the PC and server world for most of a decade and is now being phased out in favour of DDR5.

    5.7 DDR5 (2020)¶

    DDR5 is the current mainstream generation. Standard speeds started at 4800 MT/s, and the JEDEC standard now extends to 8800 MT/s at 1.1 V. That gives 38.4 GB/s per 64-bit DIMM at 4800 MT/s and 70.4 GB/s at 8800 MT/s. Each DIMM carries two 32-bit sub-channels, its own PMIC, and chips with on-die ECC and same-bank refresh. Chip capacity grew to 16, 24 and 32 Gbit, so single modules of 48 GB, 64 GB and far larger server modules are common. At the highest speeds desktop modules add a clock driver chip (the CUDIMM), and servers can use MRDIMMs; see Chapter 8.

    Example 5.2: From chip capacity to module capacity

    A DDR5 DIMM has two 32-bit sub-channels, 64 data bits in all. With x8 chips (8 data pins each), \(64/8 = 8\) chips fill one rank.

    1. With 16 Gb chips: \(8 \times 16 = 128\) Gb \(= 16\) GB per rank.
    2. With 24 Gb chips: \(8 \times 24 = 192\) Gb \(= 24\) GB per rank. Two ranks give the 48 GB modules mentioned above.
    3. With 32 Gb chips: one rank is 32 GB, and two ranks 64 GB.

    An ECC module adds check bits: \(2 \times (32 + 8) = 80\) bits per rank, which is 10 x8 chips or 20 x4 chips (Chapter 11).

    A correction to a common figure

    Some summaries quote DDR5 as "51 to 70 GB/s per DIMM". That range corresponds to 6400 to 8800 MT/s. DDR5 starts at 4800 MT/s, which is 38.4 GB/s (\(4800 \times 64 / 8 / 1000\)), so the whole standard range is 38 to 70 GB/s per DIMM.

    5.8 DDR6 (in development)¶

    JEDEC is developing DDR6, with first products expected around 2027 or later. Early public reports suggest data rates starting near 8800 MT/s and aiming towards roughly 17,600 MT/s, about twice the bandwidth of DDR5, with narrower sub-channels to keep efficiency high and a likely shift to new module formats such as CAMM-style connectors at the higher speeds. All details were still subject to change in 2026.

    5.9 DDR generations at a glance¶

    Generation Year Speed (MT/s) Voltage Prefetch Bandwidth per 64-bit channel Status
    SDR SDRAM 1993 66–133 3.3 V 1n ~1 GB/s Obsolete
    DDR 2000 200–400 2.5 V 2n 3.2 GB/s Obsolete
    DDR2 2003 400–1066 1.8 V 4n 8.5 GB/s Obsolete
    DDR3/DDR3L 2007 800–2133 1.5 / 1.35 V 8n 17 GB/s Legacy / embedded
    DDR4 2014 1600–3200 1.2 V 8n 25.6 GB/s Being phased out
    DDR5 2020 4800–8800 1.1 V 16n 38–70 GB/s Current mainstream
    DDR6 ~2027+ target ~8800–17,600 lower not stated ~2× DDR5 In development

    Example 5.3: Checking the table

    The bandwidth column follows from the top speed of each generation and a 64-bit bus: DDR \(400 \times 8 = 3200\) MB/s; DDR2 \(1066 \times 8 \approx 8.5\) GB/s; DDR3 \(2133 \times 8 \approx 17\) GB/s; DDR4 \(3200 \times 8 = 25.6\) GB/s; DDR5 \(4800 \times 8 = 38.4\) GB/s up to \(8800 \times 8 = 70.4\) GB/s. Each generation roughly doubled peak bandwidth, while the latency in nanoseconds stayed near 10 to 17 ns (Example 1.3).

    5.10 Summary¶

    • DDR moves data on both clock edges; the array runs at a few hundred MHz while the interface runs at thousands of MT/s, thanks to prefetch (2n, 4n, 8n, 16n).
    • Each generation added a feature: DQS (DDR), on-die termination (DDR2), fly-by and write levelling (DDR3), bank groups (DDR4), sub-channels, PMIC on the module, on-die ECC and same-bank refresh (DDR5).
    • DDR5 runs at 1.1 V from 4800 to 8800 MT/s; 16, 24 and 32 Gbit chips give 16 to 64 GB modules and far larger server modules.
    • DDR6 was still being defined in 2026.

    5.11 Exercises¶

    Exercise 5.1. A DDR3-1866 module has a 64-bit bus. Find its clock frequency, its peak bandwidth and the array access rate (8n prefetch).

    Answer

    Clock \(= 1866/2 = 933\) MHz. Bandwidth \(= 1866 \times 64 / 8 / 1000 = 14.9\) GB/s. Array access rate \(= 1866/8 = 233\) MHz.

    Exercise 5.2. Which generation introduced each: (a) bank groups; (b) on-die termination; (c) the data strobe; (d) the on-module PMIC; (e) fly-by topology?

    Answer

    (a) DDR4. (b) DDR2. (c) DDR (the first generation). (d) DDR5. (e) DDR3.

    Exercise 5.3. A DDR5 ECC RDIMM uses x4 chips of 16 Gb. How many chips are on one rank, and how much is data capacity and raw capacity?

    Answer

    Bits per rank: \(2 \times (32 + 8) = 80\). With x4 chips: \(80/4 = 20\) chips. Raw: \(20 \times 16 = 320\) Gb \(= 40\) GB. Data: 16 of the 20 chips, \(16 \times 16 = 256\) Gb \(= 32\) GB.

    Exercise 5.4. A DDR5 desktop module is sold as DDR5-6000 CL30. Another is DDR5-7200 CL36. Which has the lower CAS latency in nanoseconds?

    Answer

    DDR5-6000 CL30: \(30 \times 2000/6000 = 10.0\) ns. DDR5-7200 CL36: \(36 \times 2000/7200 = 10.0\) ns. They are equal; the faster module gives more bandwidth at the same latency.

    Exercise 5.5. DDR5's burst length is 16 on a 32-bit sub-channel. Explain why a DIMM can serve two cache-line requests at once but a DDR4 DIMM could not.

    Answer

    Each DDR5 sub-channel has its own command and data wires and delivers \(16 \times 32 / 8 = 64\) bytes, one cache line, per burst, so two sub-channels can serve two requests independently. A DDR4 DIMM is a single 64-bit channel with a burst of 8: it delivers one cache line per burst over the whole width, so a second request has to wait.
