    Glossary and Further Reading¶

    Glossary¶

    AOI
    Automated optical inspection: camera-based checking of assembled boards for defects.
    Array efficiency
    The fraction of a memory die's area occupied by storage cells rather than periphery and wiring.
    ATE
    Automatic test equipment: production testers that apply patterns to chips and measure the results (for example Advantest, Teradyne).
    Bank
    An independent memory array inside a DRAM chip with its own row buffer; different banks can work in parallel.
    Bank group
    A set of banks sharing some internal circuits; switching between bank groups is faster than staying in one (DDR4 and later).
    BCAT / buried wordline
    A DRAM access transistor whose gate (the wordline) is buried in a trench below the silicon surface, giving a long effective channel and very low leakage in a tiny area (BCAT: buried-channel array transistor).
    Bit, byte
    One 0-or-1 value; eight bits make a byte.
    Bitline, wordline
    The column wire that carries the data of the cells, and the row wire that opens them.
    BOM
    Bill of materials: the list of every component to buy.
    BSIM
    Berkeley short-channel IGFET model: the industry-standard family of SPICE transistor models (BSIM4, BSIM-CMG for FinFETs, BSIM-BULK).
    Burn-in
    Running parts at elevated temperature and voltage to make weak units fail before shipment.
    Burst length (BL)
    The number of consecutive transfers per read or write command, for example BL16 in DDR5.
    CAS latency (CL)
    The clock cycles from a column read command to the first data; convert to nanoseconds with CL × 2000 ÷ MT/s.
    Channel
    An independent path between memory controller and memory, with its own command and data wires.
    Courtyard
    The keep-out area around a part on a board that other parts may not enter.
    CRC
    Cyclic redundancy check: a checksum that detects corrupted data.
    CXL
    Compute Express Link: a cache-coherent protocol over PCIe wiring, used to attach memory expanders and pooled memory.
    CXL memory expander
    A device that adds DRAM capacity to a server through a CXL link instead of DIMM slots.
    Datasheet
    The manufacturer's full specification of a part: pins, voltages, timings, currents.
    Decoupling capacitor
    A small local energy tank that steadies the supply voltage.
    DFI
    DDR PHY Interface: the standard interface between a memory controller and the PHY on a chip.
    DIMM
    Dual in-line memory module: a circuit board of DRAM chips that plugs into a slot. An RDIMM is registered, with an RCD chip buffering the commands.
    DRAM
    Dynamic RAM: one transistor and one capacitor per bit; must be refreshed.
    DRC
    Design rule check: verifies that every layout shape obeys the foundry's geometric rules.
    DVFS
    Dynamic voltage and frequency scaling: lowering voltage and clock when full speed is not needed, to save power.
    ECC
    Error-correcting code: extra bits that let errors be detected and corrected (side-band, on-die or inline).
    eMRAM
    Embedded MRAM: magnetic memory built into a logic chip as non-volatile code or data storage.
    EMS
    Electronics manufacturing services: companies that assemble and test boards for other firms.
    EUV
    Extreme ultraviolet lithography (13.5 nm wavelength), used to print the finest layers of advanced logic and DRAM.
    Eye diagram
    Many bits overlaid; the open gap shows the voltage and timing margin.
    Fast-SPICE
    Circuit simulators that trade a little accuracy for huge speed-ups, making it possible to simulate whole memory arrays with parasitics.
    FD-SOI / body bias
    Fully depleted silicon-on-insulator: transistors on a thin silicon layer over a buried oxide. A body-bias voltage beneath tunes transistor strength, for example to lower SRAM Vmin.
    FinFET fin ratio
    FinFET bitcells are named by fin counts of pull-up : pass-gate : pull-down transistors, for example 111 (high density) or 122 (high current).
    Fly-by
    One wire visiting several chips in a row, like bus stops; write levelling compensates for the arrival delays.
    Gain-cell eDRAM
    Embedded DRAM using two or three ordinary transistors, storing charge on a transistor gate instead of a dedicated capacitor; needs refresh.
    GDSII
    The standard binary file format for chip layouts (layers of polygons), sent to the foundry at tapeout.
    Gerber
    The file format of each PCB layer sent to the board factory.
    Half-pitch
    Half the repeat distance of a regular pattern such as DRAM wordlines; used to name DRAM process nodes.
    High-sigma analysis
    Statistical methods that show a circuit still works at very rare variation levels (for example 6 sigma) without running billions of Monte Carlo samples.
    IDM
    Integrated device manufacturer: a company that both designs and manufactures its chips (for example Samsung, Micron, Intel).
    Impedance (Z0)
    How a wire resists a fast signal; set by trace width and spacing to the plane.
    Interposer
    A silicon (or organic) layer with fine wiring that connects dies placed side by side, for example a GPU and HBM stacks.
    ISM / DLI scheme
    The India Semiconductor Mission and its Design Linked Incentive scheme, which supports chip design and tapeout costs for Indian companies.
    JEDEC
    The industry standards body that publishes the DDR, LPDDR, GDDR and HBM specifications.
    LVS
    Layout versus schematic: proves that the circuit drawn in the layout matches the schematic netlist.
    MBIST / March C−
    Memory built-in self-test: on-chip logic that tests a memory. March C− is a classic test sequence of ordered writes and reads that detects common cell faults.
    Mirroring (MIR)
    Swapping pin functions so that chips on the back side of a board can be wired straight through.
    MPW / shuttle
    Multi-project wafer: many designs share one mask set and wafer run to split the cost. Organised shuttle programmes (for example Europractice and MOSIS) sell slots on scheduled runs.
    MT/s
    Megatransfers per second: how many times per second each data pin carries a new symbol.
    Net
    One electrical connection: every pin that must be joined together.
    NRZ
    Non-return-to-zero: two-level signalling, one bit per symbol.
    OASIS
    A newer, more compact layout file format than GDSII, used for very large designs.
    OPC
    Optical proximity correction: deliberate distortion of mask shapes so that the printed pattern on the wafer matches the intended layout.
    OSAT
    Outsourced semiconductor assembly and test company (for example ASE, Amkor, JCET).
    PAM3, PAM4
    Pulse amplitude modulation with 3 or 4 voltage levels, carrying 1.5 or 2 bits per symbol.
    PDK
    Process design kit: a foundry's device models, design rules, rule decks and libraries for one process.
    PDN
    Power delivery network: everything between the regulator and the chip.
    PEX
    Parasitic extraction: computes wire resistance and capacitance from layout for post-layout simulation.
    PHY
    The physical-layer circuits that drive and receive signals on the pins (drivers, receivers, clocking, training).
    Plane
    A whole layer of copper used for ground or one supply voltage.
    PMIC
    Power-management IC; on DDR5 modules it converts the supply into the voltages the DRAM needs.
    PoP
    Package-on-package: memory stacked directly on top of the processor package, common in phones.
    Prefetch
    The number of bits per data pin fetched from the array in one internal access (2n, 4n, 8n, 16n).
    PVT
    Process, voltage and temperature: the corners across which a circuit must work.
    QVL
    Qualified vendor list: memory parts that a platform or server maker has tested and approved.
    RAM
    Random-access memory: fast working memory in which any location is reached in about the same time; it forgets when the power is off.
    Rank
    A set of DRAM chips that together fill the channel width and are accessed together. "1Rx4" means one rank built from x4 chips.
    Raw card
    A JEDEC reference PCB design for a given memory module type and DRAM organisation.
    RCD
    Registering clock driver: buffers command, address and clock signals on RDIMMs, LRDIMMs and MRDIMMs, so the controller sees one load per module.
    Reflection coefficient (Γ)
    The fraction of a signal that bounces back from a mismatched end: \((R - Z_0)/(R + Z_0)\).
    Refresh
    Periodically reading and rewriting DRAM rows so that leaking capacitors do not lose their data.
    Reticle limit
    The largest area a lithography scanner can expose in one shot, about 26 × 33 mm (about 858 mm²); the maximum size of one chip.
    Rowhammer / PRAC
    Rowhammer: repeatedly activating a row can flip bits in neighbouring rows. PRAC (per-row activation counting) tracks activations so the DRAM can trigger protective refresh.
    Sense amplifier
    A circuit that detects a tiny voltage difference and turns it into a clean 0 or 1.
    Shmoo plot
    A pass/fail map of a chip measured across two variables, typically supply voltage and frequency.
    SI / PI
    Signal integrity and power integrity: analysis of signal quality on wires and of the power delivery network.
    SPD hub
    The DDR5 module chip holding the SPD data (and often a temperature sensor), read by the BIOS over I²C or I3C.
    SPICE
    The family of circuit simulators; ngspice is the open-source one.
    SRAM
    Static RAM: six transistors per bit; fast, no refresh; used for caches.
    Stack-up
    The order and thickness of copper and insulation layers in a PCB.
    Static noise margin (SNM)
    How much noise a stored SRAM bit can tolerate before it flips, measured from butterfly curves.
    Tapeout
    Sending a finished chip design to be manufactured.
    TCAD
    Technology computer-aided design: physics-based simulation of process steps and devices.
    Termination / ODT
    A resistor (often inside the chip, as on-die termination) that absorbs a signal to stop echoes.
    TSV
    Through-silicon via: a vertical connection through a thinned die, used to stack HBM dies.
    UVM
    Universal Verification Methodology: a standard SystemVerilog framework for building reusable testbenches.
    VCA
    Value chain aggregator: a design-service company authorised to give smaller customers access to a foundry (for example Global Unichip, Faraday, Alchip).
    Via
    A plated hole that connects copper on different layers.
    VIP
    Verification IP: ready-made models and protocol checkers for a standard interface such as LPDDR6 or AXI.
    Vmin
    The lowest supply voltage at which a memory still reads and writes correctly.
    Vref
    Reference voltage that a receiver compares an incoming signal against to decide whether it is a 0 or a 1.
    Write assist / negative bitline
    Circuits that help an SRAM write succeed at low voltage; a negative-bitline assist briefly drives the bitline below ground.
    Write levelling
    Calibration that compensates for the different arrival times of a fly-by command bus.

    Books¶

    • Bruce Jacob, Spencer W. Ng and David T. Wang, Memory Systems: Cache, DRAM, Disk: a thorough reference on the memory hierarchy, DRAM organisation and controllers.
    • Brent Keeth, R. Jacob Baker and others, DRAM Circuit Design: the circuits inside DRAM, including cells, sense amplifiers, I/O and timing.

    A final reminder¶

    Specifications for LPDDR6, HBM4, DDR6 and the highest GDDR7 speeds were still evolving in 2026, and product line-ups change every few months. Use this book to understand the concepts and the trade-offs, then confirm current figures against JEDEC documents and vendor data sheets.
