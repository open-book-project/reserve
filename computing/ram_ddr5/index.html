    About this book¶

    A textbook on random-access memory: how SRAM and DRAM cells work, how the memory families (DDR, LPDDR, GDDR, HBM and the non-volatile RAMs) differ, and how a 32 GB DDR5 server module is specified, simulated, built and tested, with a look at how memory chips are designed and made.
