    Chapter 8: Memory Module Form Factors¶

    The same DRAM chips can be packaged in very different ways. The module format decides capacity, speed, upgradeability and reliability as much as the chips do. This chapter surveys the formats in use in 2026, from the unbuffered DIMM of the desktop to the compression-mounted modules of thin laptops and AI servers and the CXL expanders that add memory beyond the slots, and then lists the helper chips that sit on a module beside the DRAM.

    8.1 UDIMM (unbuffered DIMM)¶

    The standard desktop module: the memory chips connect directly to the motherboard's memory controller with nothing in between. DDR5 UDIMMs have 288 pins. They are cheap and low in latency, but each channel supports only a limited number of chips.

    8.2 SO-DIMM (small outline DIMM)¶

    A shorter UDIMM for laptops, mini PCs and some embedded boards (262 pins for DDR5). It is upgradeable but takes board space and limits speed compared with soldered memory.

    8.3 CUDIMM and CSODIMM (clocked)¶

    These are DDR5 UDIMMs and SO-DIMMs with an added clock driver (CKD) chip that cleans up and re-drives the clock signal on the module. This helps reach DDR5-8000 and beyond on desktops and laptops, where an unbuffered clock becomes too noisy.

    8.4 RDIMM (registered DIMM)¶

    Server modules with a registering clock driver (RCD) that buffers the command and address signals. The controller drives one load per module instead of every chip, so many more chips and much larger capacities fit on a channel. The price is a little latency. RDIMMs are almost always used with side-band ECC.

    8.5 LRDIMM (load-reduced DIMM)¶

    An LRDIMM goes further than an RDIMM by also buffering the data signals with data buffer chips, allowing even higher capacity per channel. With DDR5, very large RDIMMs have made LRDIMMs less common.

    8.6 MRDIMM (multiplexed-rank DIMM)¶

    A DDR5 server module that runs two ranks at once and multiplexes them onto the bus at double speed, using special buffer chips. The first generation reaches 8800 MT/s, about 40 per cent more bandwidth than standard RDIMMs, and a second generation targets 12,800 MT/s. It needs processor support (for example, recent Intel Xeon platforms).

    8.7 CAMM2 and LPCAMM2¶

    Compression-attached memory modules: instead of an edge connector in a slot, a flat module is screwed down onto a pad of contacts on the board. This shortens the signal path, saves height and allows higher speeds. CAMM2 carries DDR5; LPCAMM2 carries LPDDR5X, giving laptops LPDDR speed and efficiency in a replaceable module.

    8.8 SOCAMM¶

    A compact compression-mounted module carrying LPDDR5X, developed for AI servers with Nvidia's Grace and Vera CPUs. It brings LPDDR's high bandwidth per watt to servers while keeping memory serviceable; a second generation, SOCAMM2, was being standardised in 2026.

    8.9 CXL memory module¶

    DRAM (usually DDR5) placed behind a CXL (Compute Express Link) controller, which talks to the processor over PCIe-style wires instead of a DDR bus. It is packaged as E3.S drives or add-in cards and adds capacity beyond the DIMM slots, at a latency roughly comparable to a remote processor socket's memory. With CXL switches, memory can be pooled and shared among servers. In the hierarchy of Figure 1.1 it is the tier between local DRAM and storage.

    8.10 NVDIMM-N¶

    A DIMM carrying DRAM plus flash and a backup power source (a supercapacitor or battery). It runs at DRAM speed; if power fails, the module copies its DRAM contents to flash and restores them at the next boot. It is used for databases and storage systems that must never lose recent writes, and is now a niche product.

    8.11 What else sits on a module¶

    A module is more than DRAM chips. The helper components, which Chapters 11 to 14 return to in detail, are:

    Component Function Where
    SPD EEPROM / SPD hub Stores the module's specifications (size, speeds, timings, including XMP/EXPO overclocking profiles); read by the BIOS at boot All modules
    PMIC Converts the 5 V (desktop) or 12 V (server) input to the DRAM voltages; moved onto the DIMM with DDR5 DDR5
    Temperature sensor Reports module temperature so the system can adjust refresh and cooling DDR5, servers
    RCD Buffers command, address and clock signals RDIMMs
    Data buffers Buffer the data signals LRDIMMs
    Decoupling capacitors Supply instantaneous current and keep supply voltage steady All
    Termination resistors Absorb signal reflections on the module All

    Many consumer modules also add a metal heat spreader, sometimes RGB LEDs with their own small controller, and a printed label with part number, capacity, speed and timings.

    8.12 Module summary¶

    Module Key feature Typical use
    UDIMM Unbuffered, direct connection Desktops
    SO-DIMM Small unbuffered module Laptops, mini PCs
    CUDIMM / CSODIMM Clock driver chip on module DDR5-8000+ desktops and laptops
    RDIMM Registered command/address via RCD; ECC Servers, workstations
    LRDIMM Data buffers as well as RCD Very high-capacity servers
    MRDIMM Multiplexed ranks; 8800 MT/s gen 1, 12,800 gen 2 Bandwidth-heavy servers (HPC, AI)
    CAMM2 / LPCAMM2 Compression-mounted, thin, fast Laptops
    SOCAMM LPDDR5X server module AI servers (Nvidia Grace/Vera)
    CXL memory module DRAM behind a CXL/PCIe link (E3.S or add-in card) Server memory expansion and pooling
    NVDIMM-N DRAM + flash + backup capacitor Storage and database servers

    The other physical forms in which RAM is found are not modules at all: soldered LPDDR in phones and thin laptops; package-on-package, where the DRAM package sits on top of the processor; HBM on a silicon interposer; and embedded SRAM, inside processors, graphics chips and almost every other chip.

    Example 8.1: Reading a module's label

    A server memory label reads "DDR5 RDIMM 1Rx4 ECC 32 GB, 4800 MT/s". The notation "1Rx4" means one rank built from x4 chips (each with 4 data pins).

    1. One rank must fill the channel width: with ECC, \(2 \times (32 + 8) = 80\) bits.
    2. With x4 chips: \(80 / 4 = 20\) chips.
    3. Data capacity with 16 Gb chips: 16 data chips \(\times\) 2 GB \(= 32\) GB, and the other four chips hold the ECC bits.
    4. The "R" in RDIMM tells us there is an RCD, so the processor sees one command load per module.

    An MRDIMM at 8800 MT/s compared with an RDIMM at 6400 MT/s offers \(8800/6400 = 1.375\) times the data rate, "about 40 per cent more".

    8.13 Summary¶

    • The module format decides capacity, speed, upgradeability and reliability.
    • UDIMM and SO-DIMM connect chips directly; CUDIMM adds a clock driver for 8000+ MT/s; RDIMM adds an RCD and ECC for servers; LRDIMM buffers data too; MRDIMM multiplexes two ranks for 8800 MT/s and up.
    • CAMM2, LPCAMM2 and SOCAMM replace the edge connector with a screwed-down flat module; CXL modules add capacity over PCIe-style wires; NVDIMM-N keeps DRAM data across power loss using flash and a backup supply.
    • Every module carries helper parts: SPD, PMIC, temperature sensors, decoupling capacitors, termination, and, for RDIMMs, an RCD.

    8.14 Exercises¶

    Exercise 8.1. Why does an RDIMM allow more chips per channel than a UDIMM?

    Answer

    The RCD buffers command and address signals, so the memory controller drives one load per module instead of one per chip. Less loading means more chips and higher capacity per channel, at the cost of a little latency.

    Exercise 8.2. Choose a module type: (a) a thin laptop that must be upgradeable and fast; (b) a gaming desktop at DDR5-8000; (c) a database server that must not lose recent writes; (d) a server needing more memory than its slots provide.

    Answer

    (a) LPCAMM2 (LPDDR speed in a replaceable module) or a DDR5 SO-DIMM. (b) CUDIMM. (c) NVDIMM-N (DRAM backed by flash and a supercapacitor or battery). (d) A CXL memory module.

    Exercise 8.3. A 2Rx8 DDR5 non-ECC UDIMM uses 16 Gb chips. How many chips does it have and what is its capacity?

    Answer

    Each rank has \(64/8 = 8\) chips, and two ranks give 16 chips. Capacity \(= 16 \times 16\) Gb \(= 256\) Gb \(= 32\) GB.

    Exercise 8.4. What do an MRDIMM and a CUDIMM each add to a DDR5 module, and what problem does each solve?

    Answer

    A CUDIMM adds a clock driver (CKD) chip that re-drives a clean clock, so unbuffered desktop modules can reach DDR5-8000 and beyond. An MRDIMM adds special buffer chips that run two ranks at once and multiplex them onto the bus at double speed, giving about 40 per cent more bandwidth than a standard RDIMM.

    Exercise 8.5. List four helper components found on a DDR5 RDIMM and say what each does.

    Answer

    SPD hub (stores the module's specifications for the BIOS), PMIC (converts the supplied 12 V into the DRAM voltages), RCD (buffers command, address and clock) and temperature sensors (report temperature so the system can adjust refresh and cooling). Decoupling capacitors and termination resistors are also present.
