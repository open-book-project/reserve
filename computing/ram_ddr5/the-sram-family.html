    Chapter 4: The SRAM Family¶

    SRAM is the fastest memory that exists, and it needs no refresh. It is built from ordinary logic transistors, so it can sit on the same chip as the processor. Its weakness is size: each bit needs several transistors, so SRAM costs far more silicon area per bit than DRAM. This chapter surveys the variants of SRAM, from the six-transistor cell inside every cache to the content-addressable memories in network routers, and shows how each trades speed, density, power and interface simplicity. For each one it states how it works, its strengths and weaknesses, and where it is used.

    4.1 6T SRAM¶

    The six-transistor cell of Section 2.2 is the workhorse. Two cross-coupled inverters form a latch and two access transistors connect it to a bitline pair. To read, both bitlines are precharged high, the wordline is raised and a sense amplifier detects which bitline starts to fall. To write, strong drivers force the bitlines to opposite values and overpower the latch.

    Strengths. Very fast, well under a nanosecond for small first-level cache arrays; no refresh; made in the same process as the logic.

    Weaknesses. Six transistors per bit make it many times larger than a DRAM cell, and SRAM cell area has shrunk only slowly at the newest process nodes (Section 15.6). Idle cells still leak current. Reading must not flip the cell and writing must flip it, and these goals conflict as supply voltage drops.

    Where it is used. Registers and register files, the L1, L2 and L3 caches of processors and graphics chips, GPU shared memory, on-chip buffers in AI accelerators and network chips, and stacked cache dies such as AMD's 3D V-Cache.

    4.2 8T and 10T SRAM¶

    An 8T cell adds a two-transistor read port to the 6T cell. A separate read wordline and read bitline sense the stored value through a buffer transistor, so a read never disturbs the latch. 10T designs add further transistors, for example for a differential read port or to allow reliable operation near the transistor threshold voltage.

    Strengths. Read stability and write ability are designed separately, so the cell works at much lower supply voltages. The separate ports allow one read and one write in the same cycle, which suits register files.

    Weaknesses. The cell is noticeably larger than 6T and needs extra wiring per cell, and the peripheral circuits are more complex.

    Where it is used. Register files in processors and graphics chips, multi-ported buffers, and ultra-low-power chips for wearables and the Internet of Things that run at very low voltage to save energy.

    4.3 Asynchronous SRAM¶

    This is a standalone SRAM chip with no clock. The system places an address on the pins, asserts chip-enable together with output-enable (to read) or write-enable (to write), and the data is valid after a fixed access time: typically tens of nanoseconds for standard parts and around 10 ns for fast ones.

    Strengths. Extremely simple to connect to a microcontroller, FPGA or older processor; predictable timing; low-power versions can retain data on a small battery for years.

    Weaknesses. Slow and low in bandwidth by modern standards; small capacities (kilobits to tens of megabits); expensive per bit compared with DRAM.

    Where it is used. Older embedded systems, industrial controllers, battery-backed configuration storage, retro computers and FPGA prototyping boards.

    4.4 Synchronous SRAM¶

    In a synchronous SRAM, inputs and outputs are registered on a clock edge. Pipelined versions add an output register for a higher clock speed; flow-through versions give data one cycle sooner. Burst modes read consecutive addresses automatically, and "zero bus turnaround" variants remove idle cycles when switching between reads and writes.

    Strengths. Much higher throughput than asynchronous SRAM, and timing that is easy to fit into a clocked design.

    Weaknesses. More pins and power; a shrinking niche because large on-chip SRAM has replaced most external caches.

    Where it is used. Networking line cards, lookup tables in telecom and test equipment, and the external second-level caches ("pipeline burst cache") on PC motherboards of the 1990s.

    4.5 QDR SRAM¶

    Quad data rate SRAM has separate read and write data ports, and each port transfers data on both clock edges. Two words in plus two words out give four transfers per clock cycle. Because reads and writes never share a bus, there is no turnaround penalty, and fully random accesses run at full speed.

    Strengths. A very high random-access rate with low, fixed latency, ideal when every access goes to a different address.

    Weaknesses. Expensive, power-hungry, small in capacity and with many pins.

    Where it is used. Packet lookup tables, flow statistics counters and queue pointers in routers and switches, and radar and other signal-processing equipment.

    4.6 PSRAM (pseudo-static RAM)¶

    Inside, PSRAM uses DRAM 1T1C cells, but a built-in controller refreshes them automatically, so the outside world sees a simple SRAM-like interface with no refresh commands. Modern parts often use a serial interface (quad SPI or 8-bit octal) with very few pins.

    Strengths. Much denser and cheaper than SRAM, typically a few megabytes in a tiny package, with a very simple interface.

    Weaknesses. Slower than true SRAM; an access that collides with an internal refresh can take longer; standby current is higher than that of SRAM.

    Where it is used. Microcontroller boards such as ESP32 modules with a few MB of PSRAM, IoT devices that drive displays or buffer audio, and older mobile phones, where it was sold as "cellular RAM".

    4.7 1T-SRAM¶

    Developed by MoSys, 1T-SRAM uses a one-transistor DRAM cell but hides refresh and row management behind an SRAM-style interface, using many small banks so that refresh rarely gets in the way of an access.

    Strengths. Several times denser than 6T SRAM while keeping SRAM-like, predictable latency.

    Weaknesses. It needs licensed technology and process support and is largely a historical design today.

    Where it is used. The Nintendo GameCube (main memory plus embedded memory in its graphics chip) and the Nintendo Wii.

    4.8 TCAM (ternary content-addressable memory)¶

    Normal RAM takes an address and returns data. A content-addressable memory works the other way round: you present a search key, every stored entry compares itself with the key in parallel, and the memory returns the address of the first match in a single operation. "Ternary" means each stored bit can be 0, 1 or X ("don't care"), so one entry can match a whole range, such as an IP prefix like 192.168.x.x. Each cell needs storage for the value and the mask, plus comparison logic.

    Strengths. Constant-time lookup no matter how large the table is; ideal for longest-prefix matching and rule tables.

    Weaknesses. Very high power (every entry is compared on every search), large area and high cost.

    Where it is used. Routers and switches for IP route lookup, access-control lists and quality-of-service rules. Simpler binary CAMs also appear inside processors, for example in the translation lookaside buffers (TLBs) that translate virtual to physical addresses.

    Example 4.1: A tiny TCAM lookup

    A router table holds three entries, kept in order from the most specific to the least specific. A bit shown as X matches either value. For clarity the keys are written as dotted decimal, where x means all eight bits are X.

    Entry Stored pattern Meaning Output port
    1 10.1.2.x one subnet A
    2 10.1.x.x a larger block B
    3 x.x.x.x everything else C

    Search for 10.1.2.7. All three entries compare at the same instant, and entries 1, 2 and 3 all match. The memory returns the first (highest-priority) match, entry 1, so the packet goes to port A. A search for 10.1.9.4 matches entries 2 and 3 only and returns B; 172.16.0.1 matches only entry 3 and returns C. Because the entries are ordered from longest prefix to shortest, "first match" is the same as "longest prefix match", which is what routers need.

    4.9 SRAM family summary¶

    Type How it works Where it is used
    6T SRAM 6 transistors per bit, no refresh needed CPU and GPU caches, registers, on-chip buffers
    8T/10T SRAM Extra transistors for a separate read port and low-voltage stability Low-power chips, register files
    Asynchronous SRAM No clock, simple interface Older embedded systems
    Synchronous SRAM Clocked interface Networking, legacy caches
    QDR SRAM Separate read and write ports, 4 transfers per clock Network packet lookup
    PSRAM DRAM cell with built-in refresh and an SRAM-style interface Microcontrollers (ESP32), IoT, older phones
    1T-SRAM DRAM cell behind an SRAM interface Nintendo GameCube and Wii
    TCAM Searches all entries at once by content Routers and switches (IP route lookup)

    4.10 Summary¶

    • SRAM is the fastest memory and needs no refresh, but costs the most area per bit.
    • Variants differ in cell (6T, 8T, 10T), interface (asynchronous, synchronous, QDR) and cell type behind the interface (PSRAM and 1T-SRAM hide DRAM cells).
    • 8T cells protect the latch from reads with a separate read port, and so work at lower voltage.
    • QDR separates read and write buses to give four transfers per clock without turnaround.
    • A TCAM compares all entries in parallel and supports "don't care" bits, giving constant-time longest-prefix lookup at a high power cost.

    4.11 Exercises¶

    Exercise 4.1. Why can PSRAM look like SRAM from outside although it is built from DRAM cells? What does it give up compared with true SRAM?

    Answer

    A built-in controller refreshes the 1T1C cells on its own, so the system never sends refresh commands and sees an SRAM-style interface. In return PSRAM is slower than true SRAM, an access that collides with an internal refresh can take longer, and standby current is higher. What it gains is density and cost: a few megabytes in a tiny, cheap package.

    Exercise 4.2. Explain in two sentences why an 8T cell can work at a lower supply voltage than a 6T cell.

    Answer

    In a 6T cell the same access transistors are used for reading and writing, so read stability and write ability pull against each other as the voltage falls. An 8T cell reads through a separate two-transistor read port that never disturbs the latch, so the two goals can be designed separately.

    Exercise 4.3. Choose the best SRAM type for each need: (a) a processor's first-level cache; (b) a router's per-packet lookup table where every access goes to a different address; (c) matching an IP address against a list of prefixes in one operation; (d) a microcontroller needing a few megabytes at low cost with few pins.

    Answer

    (a) 6T SRAM on the processor die. (b) QDR SRAM, with separate read and write ports and no turnaround penalty. (c) TCAM. (d) PSRAM with a quad or octal SPI interface.

    Exercise 4.4. Using Example 4.1's table, which port does the address 10.2.0.1 go to, and why?

    Answer

    Entry 1 (10.1.2.x) needs the second number to be 1, so it does not match. Entry 2 (10.1.x.x) also needs the second number to be 1, so it does not match. Entry 3 matches everything, so the packet goes to port C.

    Exercise 4.5. A QDR SRAM has two data ports, each 18 bits wide, on a clock of 400 MHz (a supposed figure for this exercise). Each port transfers on both clock edges. Find the data rate of one port and the total transfers per clock cycle.

    Answer

    One port makes 2 transfers per clock, so \(2 \times 400 = 800\) MT/s, and with 18 bits \(800 \times 18 / 8 = 1800\) MB/s \(= 1.8\) GB/s. Two ports (one read, one write) make \(2 + 2 = 4\) transfers per clock cycle, hence "quad" data rate; read and write together reach 3.6 GB/s, with no turnaround penalty because they never share a bus.
